Установка на iPhone:
1. Откройте опубликованную игру в Safari (не во встроенном браузере мессенджера).
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Если доступен переключатель «Открывать как веб-приложение», включите его.
5. Нажмите «Добавить».

На Android: откройте игру в Chrome, меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Важно: PWA устанавливается только по HTTPS. GitHub Pages подходит. После публикации обновите страницу; при первом посещении дождитесь загрузки игры.
