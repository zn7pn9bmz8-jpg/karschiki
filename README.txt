КТО №1 — обновлённый дизайн-концепт

Что внутри:
- index.html — готовая одностраничная демоверсия.
- Новый визуальный стиль: глубокий сине-бирюзовый / petrol, светлая мята и холодные оттенки. Без чёрно-золотой «казино»-эстетики.
- Главный элемент — личный профиль с крупной прямоугольной аватаркой, общим рейтингом и прогрессом.
- Единый рейтинг вместо отдельных таблиц по категориям.
- Лидеры, краткие показатели, достижения, улучшения и вызов сопернику.
- Можно загрузить фото и изменить ник. Фото, ник и покупки сохраняются локально в браузере на этом устройстве.

Важно:
Это только фронтенд-макет. Игроки, позиции, баллы и виртуальный баланс демонстрационные. Нет настоящих аккаунтов, общей базы, серверного рейтинга, VK-входа или реальных платежей. Загруженное фото хранится в localStorage этого браузера и не отправляется на сервер.

Публикация:
1. Распакуй ZIP.
2. Загрузи index.html в корень репозитория GitHub.
3. В Settings → Pages выбери Deploy from a branch, ветку main и папку /(root).
4. Сохрани — GitHub Pages опубликует страницу.
