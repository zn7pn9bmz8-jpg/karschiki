РОССИЯ №1 — app-like версия

Состав:
- index.html — интерфейс мини-приложения с четырьмя разделами и нижней навигацией.
- manifest.webmanifest — настройки установки как PWA.
- sw.js — Service Worker и базовое кэширование оболочки.
- icon.svg — иконка.

Что изменено:
- Новая почти чёрная графитовая тема с матовым шампанским золотом и точечными красными акцентами.
- Интерфейс ощущается как приложение: отдельные экраны, фиксированная верхняя панель и нижняя навигация, переходы между разделами.
- Защита от случайного двойного тапа для масштабирования.
- Кнопка звука — только иконка; включение/выключение.
- Более выразительные эффекты прокачки: всплывающие начисления, частицы, подсветка карточки, анимация счёта, лёгкая вибрация на поддерживаемых устройствах.
- Загрузка фото, ник и демо-прогресс сохраняются в браузере.

Как проверить на GitHub Pages:
1. Распакуй архив и замени файлы в корне репозитория: index.html, manifest.webmanifest, sw.js, icon.svg.
2. Дождись окончания публикации GitHub Pages.
3. Открой сайт по HTTPS. Чтобы не видеть старую версию, открой ссылку с новым параметром, например ?app=2.
4. Для установки на iPhone: Safari → кнопка «Поделиться» → «На экран Домой». После добавления запускай с иконки — откроется без обычной панели браузера.

Важно:
Это PWA-оболочка и фронтенд-прототип, а не настоящий многопользовательский сервис. Игроки, баллы, баланс и бусты демонстрационные. Общий серверный рейтинг, аккаунты, синхронизация между устройствами и реальные платежи не подключены.
Service Worker может кэшировать предыдущую оболочку. При обновлении версии можно поменять CACHE в sw.js (например, russia-no1-app-v2), чтобы принудительно создать новый кэш.
