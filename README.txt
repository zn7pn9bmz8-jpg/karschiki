КТО №1 — демонстрационный прототип

Как посмотреть:
1. Откройте index.html в браузере или загрузите файл в корень GitHub-репозитория.
2. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Что работает в демо:
- переключение рейтингов: влияние, капитал, престиж, достижения;
- виртуальные покупки и изменение демо-баланса;
- окно вызова соперника;
- кнопка поделиться профилем.

Важно:
Это только фронтенд-макет. Игроки и рейтинги вымышленные, баланс виртуальный,
реальные платежи, авторизация ВКонтакте, сервер и общая база пока не подключены.
Следующий этап — согласовать внешний вид и механику, затем подключить серверную
часть (например, Cloudflare Pages/Workers + Supabase) и только после этого
разрабатывать безопасную платёжную интеграцию.
