РОССИЯ №1 — тёмная VIP-версия интерфейса

Внутри:
- Почти чёрная графитовая тема с матовыми мятно-зелёными акцентами.
- Заголовок «Стань №1 в России» и обозначение единого рейтинга страны.
- Крупный профиль, фото, позиция и общий рейтинг.
- Матовые кнопки прокачки.
- Анимация нажатия, всплывающие начисления, частицы и подсветка профиля при улучшении.
- Звуковые эффекты через Web Audio API. По умолчанию звук выключен; включается кнопкой «ЗВУК».
- Ник, фото и локальный демо-прогресс сохраняются в браузере.

Важно: это фронтенд-демо. Рейтинг, игроки, баланс и улучшения пока демонстрационные; сервер, общая база, настоящие аккаунты и платежи не подключены.

Обновление GitHub Pages:
Замените index.html в репозитории. Дождитесь завершения публикации. Если Safari показывает старую версию, откройте ссылку с новым параметром, например ?v=vip1.
