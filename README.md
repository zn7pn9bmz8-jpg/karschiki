AVIATOR — обновление шапки, аватарки и звука

Заменить в GitHub Pages только три файла внутри папки static:
- static/index.html
- static/style.css
- static/game.js

В архиве они находятся в aviator_fixed/static/.

Изменения:
- исправлена ошибка порядка объявления функции, из-за которой аватар мог не появляться при первой загрузке;
- аватар из локального профиля отображается сразу при открытии страницы;
- в шапке сохранено название «КАРЩИКИ»;
- звук — белая кнопка только с SVG-иконкой, без эмодзи и текста; иконка меняется при включении/выключении;
- добавлена кнопка «ВЫВЕСТИ ДЕНЬГИ», которая открывает только информационное окно о недоступности вывода;
- удалена ссылка на пополнение через внешний сервис; используются только виртуальные игровые очки;
- удалена загрузка Telegram WebApp SDK: страница работает как обычный сайт.

Важно: если аватар был сохранён в Safari на том же устройстве и в том же домене, он должен подхватиться из localStorage. Если данные сайта были очищены или раньше использовался другой домен/браузер, фото нужно загрузить в профиле ещё раз.
