# Татарск Такси — компактная версия

## Что изменено
- Главный экран сразу открывает форму заказа.
- Убраны рекламные/объяснительные блоки и длинные инструкции.
- Крупные поля маршрута и большая кнопка.
- Нижняя навигация: «Заказать», «Заказы», «Профиль».
- Добавлены manifest, иконка и service worker для PWA.

## Публикация на GitHub Pages
Загрузите ВСЕ файлы из этой папки в корень репозитория (рядом друг с другом), заменив старые `index.html`, `style.css`, `app.js`.
В настройках GitHub Pages оставьте `main` и `/(root)`.

## Важно
Это только демонстрационный интерфейс. Заявки не передаются водителям, нет реальной базы данных, регистрации или диспетчеризации. Для реальных поездок необходим взрослый организатор, проверка водителей и безопасная обработка персональных данных.
