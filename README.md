# Татарск Такси — тестовая система заказов

## Установка
Замените файлы в корне GitHub-репозитория файлами из этого архива. Не загружайте папку целиком — загрузите сами файлы в корень.

## Проверка
1. Откройте приложение в режиме «Пассажир» и создайте заказ со своими адресами.
2. Нажмите переключатель режима вверху и выберите «Я водитель».
3. Найдите свою заявку и нажмите «Предложить цену».
4. Введите тестовую цену и отправьте предложение.
5. Вернитесь в режим «Пассажир» и нажмите «Выбрать водителя».

Данные тестовых заявок хранятся только в localStorage этого браузера. Они не синхронизируются между разными телефонами и не отправляются реальным водителям. Для общей работы нескольких пользователей потребуется серверная база данных и безопасная авторизация.

Для реальных поездок необходим взрослый организатор, который отвечает за проверку водителей, безопасность и законную обработку данных пассажиров.
