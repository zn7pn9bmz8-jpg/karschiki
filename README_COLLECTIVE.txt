ОБЩИЙ ОНЛАЙН-РЕЙТИНГ «КАРЩИКОВ»

Игра сохранена. Новый блок рейтинга добавлен отдельно внизу страницы.
Чтобы рейтинг стал общим для всех телефонов, один раз подключите бесплатный проект Supabase.

1. Создайте проект на https://supabase.com/ (для шести участников бесплатного тарифа обычно достаточно; лимиты и условия сервиса могут меняться).
2. В панели проекта откройте SQL Editor -> New query.
3. Скопируйте весь файл supabase_setup.sql в запрос и нажмите Run.
4. Откройте Project Settings -> API (или раздел Data API / API Keys в актуальном интерфейсе).
5. Скопируйте Project URL и публичный anon / publishable key.
6. Откройте static/collective-config.js и замените два значения:
   - ВСТАВЬТЕ_SUPABASE_PROJECT_URL -> ваш Project URL
   - ВСТАВЬТЕ_SUPABASE_ANON_KEY -> ваш публичный anon/publishable key
7. Загрузите обновлённую папку проекта на хостинг. Если GitHub Pages уже опубликован, замените содержимое папки static и добавьте два новых файла collective.js и collective-config.js.
8. Откройте страницу, введите имя и нажмите «ПОДКЛЮЧИТЬСЯ». Разошлите всем одну и ту же ссылку.

КАК ЭТО РАБОТАЕТ
- Каждый браузер получает свой случайный ID и запоминает имя локально.
- Участник появляется в общем списке сразу после подключения, даже если ещё не сыграл.
- Завершённые поездки отправляются в общую базу.
- Рейтинг можно смотреть за сегодня, неделю или за всё время.
- Обновление результатов происходит после поездки и автоматически примерно раз в 15 секунд.
- Игровой баланс, ставки, промокоды, профиль, анимации и механика не синхронизируются и не переписываются.

ВАЖНО ПРО БЕЗОПАСНОСТЬ
В браузер помещается только публичный anon/publishable key. Никогда не вставляйте service_role / secret key в HTML или JavaScript.
SQL-политики рассчитаны на небольшой дружеский рейтинг по общей ссылке. Имя и отправляемые браузером результаты не подтверждаются сервером, поэтому технически участник может подделать результат или чужое имя. Это простой общий рейтинг для своей компании, а не защищённый денежный сервис или честный киберспортивный турнир.
