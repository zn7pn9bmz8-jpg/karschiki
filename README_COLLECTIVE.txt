ОБЩИЙ ОНЛАЙН-РЕЙТИНГ «КАРЩИКОВ» — ПОДКЛЮЧЕНИЕ

В архиве уже заполнены Project URL и публичный Publishable key вашего Supabase.

ВАЖНО: приложение версии 12 ожидает таблицы public.players и public.game_rounds.
Если таблицы players и game_rounds уже созданы, повторный запуск SQL безопасен: он добавит недостающие поля bet_amount и earned.

1. В Supabase откройте SQL Editor -> New query.
2. Откройте файл aviator_fixed/supabase_setup.sql из этого архива.
3. Скопируйте его целиком в SQL Editor и нажмите Run.
4. После успешного выполнения загрузите на GitHub содержимое папки aviator_fixed
   (с сохранением структуры папок), заменив прежние файлы.
5. Откройте игру, введите имя и нажмите «ПОДКЛЮЧИТЬСЯ». Если имя уже сохранено в этом браузере, подключение произойдёт автоматически.

В рейтинге используются таблицы players и game_rounds. Результаты и имена
передаются из браузера. В рейтинг записываются фактическая ставка и чистый выигрыш,
поэтому общий заработок корректно считается даже при разных размерах ставок. Это упрощённый рейтинг для небольшой компании: данные,
отправляемые клиентом, не проходят серверную проверку и технически могут быть
подделаны. Не используйте его для денежных расчётов или ценных призов.

В браузере используется только публичный Publishable key. Никогда не добавляйте
в HTML/JS service_role или secret key.
